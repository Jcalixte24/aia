# AIA · Association Ivoirienne d'Astronomie

Site vitrine immersif (HTML/CSS/JS, sans build) : télescope 3D qui se décompose au scroll, globe, constellation de navigation, équipe, activités, événements, journal.

- `index.html` : toute la page (CSS et JS inclus)
- `images/` : logo, photos et textures (Terre, Lune)
- `vercel.json` : en-têtes et cache pour Vercel

Aperçu local : `python -m http.server 5173` dans ce dossier, puis http://localhost:5173 (nécessaire pour la Terre 3D).
Déploiement : Vercel, dossier racine, aucune commande de build.

Sources des contenus : `infos-collectees.md`.
